Before you copy.

A few useful answers.

More in the documentation ↗
Do my devices need to be on the same network?+

Yes. Connect your devices to the same local Wi-Fi or Ethernet network. Carryover discovers devices locally and shares clips between them. It does not offer internet or remote-network syncing.

How are my clips protected?+

Your devices share a group key and use authenticated encryption for clipboard transfers. Invite links and QR codes contain that shared secret: anyone with it can read what the group copies, so only share it with your own devices. Recent clips are stored locally. Read the protocol and its limitations.

How does it work on iPhone?+

Opening Carryover sends a newly copied item from your iPhone, or retrieves the latest clip from your other devices. It does not sync continuously in the background. The iPhone app currently requires building with Xcode; there is no App Store download.

Which Linux desktops are supported?+

The current x86_64 package targets KDE Plasma and Bazzite with compatible runtime libraries. GNOME Wayland is unsupported. Linux installations and updates are manual. The Linux guide lists dependencies and setup steps.

What can I copy between devices?+

Plain text and PNG images. That includes links, code snippets, and screenshots. Carryover is a clipboard sharing utility; it does not transfer files or preserve rich text formatting.

What does “early release” mean?+

The app is usable, but setup and testing vary by platform. The Mac app is not notarized yet, the iPhone app needs an Xcode build, and Linux has specific desktop and library requirements. Check the current support status before installing, and report problems on GitHub.
