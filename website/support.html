Support

Let’s get your devices talking.

For help with Carryover, email determantechhelp@gmail.com. Include your device models, operating system versions, Carryover version and the steps that failed. Please do not include pairing codes, invite links, or private clipboard contents.

Set up your devices

  1. Install Carryover on your computer from the latest release and keep it running.
  2. On your first device, start a group. Choose Add a Device to show its QR code or invite link.
  3. On iPhone or iPad, choose I already use Carryover, then scan the QR code or paste the invite link. Join only a group made on your own devices.
  4. Keep devices on the same local network, allow local network access, and open Carryover on your iPhone or iPad to sync.

The Mac download is not notarized yet. If macOS blocks the app, use System Settings → Privacy & Security → Open Anyway after attempting to open it. On Windows, allow Carryover through the firewall for your trusted private network. Linux desktop packages currently target KDE Plasma/Bazzite with compatible runtime libraries.

If a clip does not arrive

  • Confirm Carryover is running and syncing is enabled on each computer.
  • Check that every device joined the same group and is on the same Wi-Fi/local network. Guest networks may block communication between devices.
  • On iPhone or iPad, check Settings → Privacy & Security → Local Network. In Carryover, Settings → Setup Guide walks through permissions.
  • Opening the phone app sends a newly copied supported item, or retrieves the latest clip if there is nothing new to send. Get Latest fetches from your computers; Paste to Send lets you explicitly paste an item.
  • iPhone and iPad syncing happens while the app is open, not continuously in the background. Carryover shares plain text and images, not files or rich text formatting.

History, pairing and privacy

Use Recent to copy an item again, delete one item, or Clear Recent. Settings → Leave Group removes the iPhone or iPad's saved pairing and history. It does not erase other devices' copies or the system clipboard. Read the privacy policy for details.

More help

Read the iPhone setup guide, check release notes, or report a bug on GitHub. GitHub issues are public: use email for private support requests.
